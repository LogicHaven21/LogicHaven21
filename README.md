- [Product Image Batcher](https://github.com/LogicHaven21/product-image-batcher) — A tool that fits a batch of photos into a consistent layout and exports them in a single ZIP file.
- [Family Health Tracker](https://github.com/LogicHaven21/family-health-tracker) — A Persian-language app for tracking blood pressure and blood glucose at home and sharing a printable report with a doctor.
